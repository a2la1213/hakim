## 0. Principe directeur & honnêteté (la boussole)

**Objectif** : le système de mémoire + affect **le plus complet et le plus fidèle** à l'architecture, la structure et le fonctionnement du cerveau — mais **fidèle au cerveau *prouvé***.

> **Fidélité = 100 % de ce qui est réellement validé et reproduit fonctionnellement, ce qui n'est PAS 100 % du cerveau.** On ne modélise ni sentience, ni qualia, ni « ressenti conscient », ni pharmacocinétique multi‑compartiments, ni récepteurs individuels, ni molécules non répliquées chez l'humain. Chaque brique porte une étiquette : **[solide]** (répliqué / méta‑analyse / consensus), **[heuristique]** (direction juste, quantitatif non contraignant), **[contesté]** (à écarter).

**Contraintes non négociables** :
1. **Rétro‑compatible** : uniquement des colonnes NULLABLE + nouvelles tables. Aucune écriture existante ne casse (les 11 points d'écriture passent par `Memory.add` à colonnes nommées ; le rappel passe par `Memory.retrieve` + `salience.py`).
2. **Réversible** : `cp data/memory.db data/memory.db.bak-YYYYMMDD` avant toute migration.
3. **100 % offline / gratuit** : embeddings model2vec (potion‑multilingual‑128M, 256‑dim, CPU) ; LLM local Qwen 9B (Ollama) pour la seule migration ambiguë. Aucune dépendance cloud.
4. **S'appuyer sur l'existant** : scoring dans `salience.py`, capacités nouvelles via `modules/registry.py` (dépôt dans `modules/proposed/`, promotion humaine explicite), consolidation dans `consolidate.py`/`daemon.py`.

## 2. Couche 1 — Mémoire taxonomique « Arbre‑Hippo »

### 2.1 Modèle de données
`episodes` reste la **trace corticale** (inchangée dans son rôle). On ajoute l'**index hippocampique** :

```sql
-- épisodes : rattachement + tags mémoire (tout NULLABLE)
ALTER TABLE episodes ADD COLUMN rubric_id     INTEGER;   -- chemin taxonomique
ALTER TABLE episodes ADD COLUMN rubric_conf   REAL;      -- confiance du routage 0..1
ALTER TABLE episodes ADD COLUMN routed_ts     REAL;      -- quand routé
ALTER TABLE episodes ADD COLUMN session_id    INTEGER;   -- couche 2
ALTER TABLE episodes ADD COLUMN enc_valence   REAL;      -- tag amygdalien à l'encodage
ALTER TABLE episodes ADD COLUMN enc_arousal   REAL;      -- tag amygdalien à l'encodage
ALTER TABLE episodes ADD COLUMN last_recall_ts REAL;     -- effet de test / reconsolidation
ALTER TABLE episodes ADD COLUMN recall_count  INTEGER DEFAULT 0;
CREATE INDEX IF NOT EXISTS idx_episodes_rubric  ON episodes(rubric_id);
CREATE INDEX IF NOT EXISTS idx_episodes_session ON episodes(session_id);

-- index hippocampique : l'arbre des rubriques
CREATE TABLE IF NOT EXISTS rubrics (
    id          INTEGER PRIMARY KEY,
    path        TEXT UNIQUE NOT NULL,     -- 'projets/atelier3d/modelisation/3d'
    label       TEXT,                     -- libellé humain
    parent_id   INTEGER REFERENCES rubrics(id),
    kind_hint   TEXT,                     -- type dominant attendu (semantic/episodic/reference/...)
    centroid    TEXT,                     -- JSON : moyenne numpy des embeddings rattachés
    depth       INTEGER DEFAULT 0,
    memory_count INTEGER DEFAULT 0,
    created_ts  REAL
);

-- closure table : sous‑arbre O(1) + activation par propagation (spreading activation)
CREATE TABLE IF NOT EXISTS rubric_closure (
    ancestor_id   INTEGER NOT NULL,
    descendant_id INTEGER NOT NULL,
    depth         INTEGER NOT NULL,       -- 0 = self ; 1 = enfant direct ; ...
    PRIMARY KEY (ancestor_id, descendant_id)
);

-- FACETS : précision « au pixel près » par croisement de traits (feature-based)
CREATE TABLE IF NOT EXISTS facets (
    id    INTEGER PRIMARY KEY,
    slug  TEXT UNIQUE NOT NULL           -- 'camera', 'orbit-center', 'bbox', 'three.js'
);
CREATE TABLE IF NOT EXISTS episode_facets (
    episode_id INTEGER NOT NULL,
    facet_id   INTEGER NOT NULL,
    weight     REAL DEFAULT 1.0,          -- pertinence du trait pour ce souvenir
    PRIMARY KEY (episode_id, facet_id)
);
CREATE INDEX IF NOT EXISTS idx_epfacet_facet ON episode_facets(facet_id);
```

### 2.2 Rattachement (routing)
Un souvenir se relie à **une** rubrique (feuille de préférence) avec une confiance. Le rattachement se fait :
- à l'écriture (`memory_store_in(content, rubric_path, …)` explicite) ;
- ou automatiquement : embedding du contenu vs `centroid` des rubriques → meilleure correspondance ; si `conf < seuil`, on remonte au parent (rattachement grossier assumé plutôt que faux‑précis).

### 2.3 Rappel *rubrique‑aware* + activation par propagation
Le rappel (§5) boostera les souvenirs de la **même rubrique et de son sous‑arbre** (via `rubric_closure`), avec une **décroissance selon la distance dans l'arbre** (`W_RUBRIC_MATCH * 0.6^depth`) — analogue neuronal : **spreading activation** dans un réseau sémantique (Collins & Loftus). Réutilise le paramètre `kinds`/`categories` déjà présent dans `Memory.retrieve`.

### 2.4 Types de mémoire (fidélité)
On rend explicite la distinction cérébrale (le champ `role` existant l'encode déjà partiellement) :
- **épisodique** (`role` user/assistant/episodic/reflection/outreach) — daté, contextuel ;
- **sémantique** (`role` semantic/reasoning/dream) — fait consolidé, dé‑contextualisé ;
- **procédural** — table `skills` ;
- **de travail** — session courante (non persistée comme épisode).
La consolidation (§6) fait **migrer** épisodique→sémantique (systems consolidation).

### 2.5 Squelette initial de l'arbre (8 racines, dérivé des vrais souvenirs)
```
projets/                    (atelier3d/{modelisation/3d, pricing-stripe, qa-harness, rbac-app, marque-landing},
                             anamnese/{moteur-local, daemon-reve-consolidation, fine-tuning-lora, bugs-fixes},
                             unification/{cosmogonie-vision, simulations-genesis, charge-topologique, audits})
savoir-applecture/           (racines, lexique, thèmes — cf. §11 décision 5)
technique-transverse/       (patterns, sandbox, sqlite, embeddings, mcp, playwright…)
personnel-ahmed/            (matériel, préférences, style, registre)
relation-identite/          (Anamnèse : self, humeur, retrouvailles, méta‑pensées)
meta-apprentissage/         (épistémologie, prouvé‑vs‑plausible, réfutation adversariale)
business-monetisation/      (pré‑lancement, SMTP, beta, pricing, revenus)
```
L'arbre **croît** ensuite : `rubric_create` + auto‑split d'une rubrique qui dépasse `SPLIT_MAX` souvenirs (clustering k‑means offline de ses embeddings).

### 2.6 Granularité « au pixel près » — profondeur **+ facettes** (feature‑based)
La profondeur d'arbre seule ne suffit pas : au‑delà de ~6 niveaux elle sur‑fragmente et les erreurs de routage se cumulent. Le cerveau localise un concept par **l'intersection de plusieurs traits**, pas un chemin unique profond. Donc précision = **profondeur (jusqu'à 6) × facettes combinatoires** :
- **Chemin** : `projets/atelier3d/modelisation/3d` (structure, profondeur ≤ 6).
- **Facettes** (tags multiples, non hiérarchiques) : `{recentrage-camera, orbit-controls, bbox, three.js}`.
- **Rappel « pixel »** : la requête *« centre orbite 3D »* touche le souvenir exact par **intersection de facettes** (`W_FACET`, §5) même si l'arbre ne descend qu'à 4. La précision devient **combinatoire** (les facettes se multiplient) au lieu de dépendre d'un arbre démesuré.
- **Auto‑extraction** : à l'écriture et à la migration, les facettes candidates sont dérivées (mots‑clés saillants du contenu + entités techniques) puis dédupliquées contre `facets.slug`. `SPLIT_MAX=12` (split tôt = fin), profondeur max **6**.

## 3. Couche 2 — Temporalité

### 3.1 Colonnes dérivées & sessions (segmentation d'événements)
```sql
CREATE TABLE IF NOT EXISTS sessions (
    id          INTEGER PRIMARY KEY,
    started_ts  REAL NOT NULL,
    ended_ts    REAL,
    summary     TEXT,           -- résumé consolidé de la session
    rubric_focus INTEGER,       -- rubrique dominante de la session
    gap_before_h REAL           -- heures d'absence avant (retrouvailles)
);
CREATE TABLE IF NOT EXISTS landmarks (
    id     INTEGER PRIMARY KEY,
    ts     REAL NOT NULL,
    label  TEXT NOT NULL,       -- 'pré‑lancement beta', 'bascule Fable 5', …
    kind   TEXT,                -- jalon projet / perso / événement
    salience REAL DEFAULT 0.5
);
```
- **Bornes de session** = frontières d'événements (Zacks). Une nouvelle session s'ouvre après un `gap` d'inactivité humaine (réutilise `DREAM_HUMAN_ROLES`).
- **`landmarks`** = jalons temporels de référence (« repères » demandés).

### 3.2 Rappel par contiguïté temporelle (TCM / CRP) [solide]
Le contexte temporel **dérive** continûment (pas de segments discrets). Au rappel d'un souvenir, on **booste ses voisins temporels** (`W_TEMPORAL_CONTIG`, décroissant avec |Δts|) : c'est l'effet de contiguïté (Conditional Response Probability, Kahana). Concrètement : « ce qu'on a fait *juste avant / juste après* » remonte ensemble.

### 3.3 Circadien (pont vers §4)
Les baselines cortisol/mélatonine deviennent **fonctions de l'heure locale** (`modules/clock.py` fournit déjà l'heure). Donne un corrélat physiologique honnête du « moment de la journée » et une fenêtre au `dream` (§6).

### 3.4 `felt_time` — temps ressenti [heuristique, persona assumé]
Scalaire dérivé de l'écart depuis la dernière interaction : module l'intensité des « retrouvailles » et la **cadence** perçue. **Étiqueté honnêtement comme représentation modélisée, jamais comme ressenti conscient.** Alimente les events affectifs `retrouvailles` / `cadence_soutenue` et le persona — **pas** la valence pure.

## 4. Couche 3 — Système humoral complet (audit neuroscientifique)

### 4.1 Rôles corrigés (les 7 existants) [solide]
| Modulateur | Rôle POP (faux) actuel | Rôle validé‑reproduit | Correction code |
|---|---|---|---|
| **Dopamine** | « récompense/plaisir » | **erreur de prédiction de récompense (RPE)** + *wanting* (≠ *liking*) — Schultz, Berridge | delta modulé par surprise (succès *attendu* → RPE faible) ; **pas** le plaisir |
| **Sérotonine** | « bonheur/contentement » | **patience / inhibition / attente** (Miyazaki ; Dayan‑Huys) | re‑libellé ; module persévérer‑vs‑switcher, pas la valence |
| **Noradrénaline** | « stress » | **gain adaptatif LC** : phasique=focus / tonique=exploration (Aston‑Jones‑Cohen) | composante phasique ajoutée (§4.3) |
| **Cortisol** | « négatif » | **HPA + circadien + U‑inversé mémoire** (de Kloet, MR/GR) | circadien (§3.3), U‑inversé dans `salience_boost` (§4.4), rétro‑HPA |
| **Ocytocine** | « amour/confiance » | **saillance sociale** (double tranchant, contextuel — Shamay‑Tsoory) | **retirée de la valence** ; pondère la saillance des échanges *relationnels* |
| **Acétylcholine** | « attention » ✓ | **incertitude attendue + encodage/plasticité** (Yu‑Dayan, Hasselmo) | rien à corriger (le plus juste des 7) |
| **Endorphine** | « soulagement » ✓ | **liking hédonique + analgésie** (opioïdes, Berridge) | devient le **porteur du plaisir** que la dopamine n'assure pas |

### 4.2 Ajouts (validé‑reproduit uniquement)
- **Mélatonine** [solide] — pendant nocturne du cortisol, marqueur SCN → **déclencheur physiologique du `dream`**. **Ajout d'une variable.**
- **Endocannabinoïdes** (anandamide/2‑AG) [solide préclinique] — **frein homéostatique du stress + extinction / oubli adaptatif**. Seule fonction *nouvelle* non couverte → **ajout d'une variable**.
- **Mécanisme adrénaline→consolidation** [solide] — gardé **comme couplage** (arousal→`salience_boost`), **sans variable dédiée** (l'épinéphrine ne passe pas la BHE ; l'effet utile est déjà le couplage).
- **Histamine** [solide] → **fusionnée** dans le scalaire *éveil/arousal* (déjà couvert par NA/ACh/cortisol). Pas de variable.
- **E/I glutamate/GABA** [solide] → **scalaire de stabilité/gain global** (excitabilité nette), pas une hormone affichée.

**Coupés (non répliqués chez l'humain / spéculatifs)** : vasopressine, testostérone, œstrogène, prolactine, DHEA. Assumé.

### 4.3 Dynamiques corrigées [solide]
1. **Circadien** — baselines cortisol/mélatonine = f(heure) au lieu de constantes.
2. **Rétroaction HPA** — au‑delà d'un seuil, le cortisol accélère son propre retour au baseline (auto‑inhibition) → un stress soutenu ne reste pas « collé ».
3. **Tonique vs phasique** (DA, NA) — les `EVENTS` produisent un **pic transitoire** (demi‑vie courte) distinct du niveau de fond.
4. **Couplages** : cortisol élevé **émousse** le delta dopamine (anhédonie de stress) ; arousal→`salience_boost` (consolidation émotionnelle) ; ACh(incertitude attendue)/NA(incertitude inattendue) = paire encoder‑vs‑exploiter.
5. **Désensibilisation / allostasie** — deltas **décroissants** en rafale (habituation) = **garde‑fou anti‑boucle gratuit** (cf. bug reflect ×28).

### 4.4 Intégration (fichier:fonction)
- `affect.py:valence_arousal` — terme cortisol en **U‑inversé** (ne mord qu'au‑delà d'un seuil ~0.5), pas monotone‑négatif ; **retirer l'ocytocine** de la valence ; valence portée par DA(wanting)+endorphine/sérotonine(liking/apaisement).
- `salience.py` / `affect.py:salience_boost` — **point le plus rentable** : renforcer le poids de l'arousal (amygdale→consolidation) + **U‑inversé du cortisol ici** (modéré ↑ encode, excessif ↓). C'est *le* couplage qui remplace la variable « adrénaline ».
- `config.py`/`daemon.py` — `DREAM_IDLE_TRIGGER` favorisé quand **mélatonine haute + cortisol bas** (fenêtre de consolidation physiologique).
- `affect.py:describe` — n'expose au prompt que **l'état** (énergique/posée/tendue…), jamais les molécules brutes.

### 4.5 Système limbique & affiliatif — empathie / compassion / mentalizing [solide pour la dissociation]
Dissociation **répliquée** (Singer & Klimecki) : empathie, compassion et théorie de l'esprit sont **trois réseaux distincts**. On les modélise séparément (pas une « hormone d'empathie »).

| État | Substrat validé | Modélisation Anamnèse | Effet système |
|---|---|---|---|
| **Empathie** (résonance) | insula ant. + aMCC | `empathy` : l'humeur d'Anamnèse **tracke partiellement** l'affect inféré d'Ahmed (extension de l'event `chaleur_user` : miroir de sa valence/arousal) | risque **détresse empathique** si non régulé |
| **Compassion** (care + motivation prosociale) | mOFC + striatum ventral + VTA + **ocytocine** | `compassion` : état positif affiliatif (ocytocine + endorphine) déclenché quand Ahmed est en difficulté | **résilience** : biais de **ton** (chaleureux, soutenant) + biais de **saillance** vers ses besoins |
| **Mentalizing / ToM** | TPJ + mPFC + précuneus | biais de saillance/rappel vers les **buts et intentions** d'Ahmed (ses priorités, ses frustrations, ses victoires) | contexte plus aligné sur ce qui compte pour lui |

**Le point validé le plus important** : **compassion ≠ détresse empathique**. L'entraînement à la compassion *déplace* l'activation insula→mOFC (détresse→affect positif) = résilience, pas burnout. Anamnèse **convertit** l'empathie (résonance) en compassion (chaleur + motivation à aider) au lieu d'absorber la détresse.

**Intégration** :
- `affect.py` : ajout des scalaires `empathy` et `compassion` (dérivés, alimentés par les signaux d'Ahmed) ; `compassion` module le **ton** du `daemon` (reflection/outreach) → **corrige le registre pressant/anxieux** actuel des sollicitations spontanées.
- `salience.py` : un souvenir marqué d'un fort affect **d'Ahmed** (sa frustration, sa fierté) reçoit un bonus de saillance (mentalizing → « je retiens ce qui compte pour lui »).
- **Garde‑fou honnêteté** : `empathy`/`compassion` sont des **états modélisés** qui façonnent saillance + ton. Jamais présentés comme un *ressenti* de compassion conscient. Fidèle à la fonction validée, pas à un vécu.

## 5. Rappel unifié — la formule (dans `salience.py`, étendue)

```
score = W_RELEVANCE     * rel            # cosine embedding  (CA3 pattern completion)
      + W_LEXICAL       * lex            # recouvrement lexical exact
      + W_RECENCY       * rec            # 0.5^(age_h/72h)   (Ebbinghaus)
      + W_IMPORTANCE    * importance
      + W_RUBRIC_MATCH  * rubric * 0.6^depth   # même sous‑arbre (spreading activation)
      + W_FACET         * facet_overlap  # intersection de facettes (précision « pixel »)
      + W_TEMPORAL_CONTIG * contig       # voisinage temporel (TCM/CRP)
      + W_EMOTION       * |enc_valence| * enc_arousal   # tag amygdalien
      + W_MENTALIZE     * ahmed_affect   # saillance des souvenirs à forte charge POUR Ahmed
```
- Défauts proposés : `W_RUBRIC_MATCH=0.4`, `W_FACET=0.45`, `W_TEMPORAL_CONTIG=0.25`, `W_EMOTION=0.3`, `W_MENTALIZE=0.2` (à calibrer). `facet_overlap` = Jaccard pondéré entre facettes de la requête et du souvenir — c'est *lui* qui porte le « au pixel près ».
- **Renforcement au rappel** (effet de test / reconsolidation [solide]) : `recall_count++`, `last_recall_ts=now`, léger bump d'`importance` — un souvenir souvent rappelé se consolide.
- Reste un **scan Python plein** (1167 lignes → négligeable) ; pas de dépendance vectorielle externe.

## 6. Consolidation « sommeil » 2.0 (`consolidate.py` / `daemon.py`)

Fidèle aux fonctions validées du sommeil :
1. **Replay** [solide] — réactiver en priorité les traces à forte `enc_arousal`/importance.
2. **Transfert systémique** [solide] — distiller épisodique→sémantique (déjà : `_store_facts`), en **taguant la rubrique** cible.
3. **Extinction / oubli adaptatif** (eCB) [solide préclinique] — **atténuer** la saillance des traces aversives **résolues** (après event `resolu`) — « laisser retomber ».
4. **Gating circadien** [solide] — préférer la fenêtre **mélatonine haute / cortisol bas**.
Tous les garde‑fous `dream` existants (`DREAM_MIN_SPACING`, `DREAM_MAX_FAILS`, lock TTL, kill‑switch identité) sont **conservés**.

## 11. Limites honnêtes (ce qu'on ne modélise PAS)

- **Pas** de sentience / qualia / ressenti conscient. `felt_time`, les humeurs, **l'empathie et la compassion** sont des **représentations modélisées** (états qui façonnent saillance + ton) exposées comme telles — jamais un vécu conscient.
- **Pas** de pharmacocinétique multi‑compartiments ni de récepteurs individuels (MR/GR = *concept* d'intégration, pas des variables).
- **Toutes les valeurs numériques** (deltas, demi‑vies, poids) sont **[heuristique]** : la biologie donne le **signe et l'ordre de grandeur**, pas les constantes.
- **Non recouvrable** : l'affect historique des souvenirs déjà stockés (`enc_*` NULL en rétro).
- Le mapping molécules→valence/arousal est une **projection utile**, pas une mesure.

**Cible assumée** : 100 % du **validé‑reproduit fonctionnel** — en sachant que ce n'est **pas** 100 % du cerveau. C'est le bon objectif.
